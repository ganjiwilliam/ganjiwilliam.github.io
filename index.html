Canny Edge Detector Integrated with System Bus, Memory & UART

A complete image-processing SoC pipeline built around a hardware edge-detection accelerator.

  • Integrated a Verilog-based Canny edge detector accelerator with a custom system bus, SRAM memory, and a UART transmitter to form a full image-processing SoC pipeline.
  • Modeled transistor-level schematics in LTspice targeting a standard 180 nm process node for transient design verification.
  • Validated output accuracy at every pipeline stage — Gaussian smoothing, gradient, direction, non-maximum suppression, and hysteresis — against reference images, achieving a 98.28% pixel-level match across five test images.

Dynamic Cache Replacement Policy Simulator

LIP, BIP, and DIP replacement policies implemented and benchmarked in ChampSim.

  • Implemented LIP, BIP, and DIP as custom C++ replacement modules in the ChampSim simulator across 5 real-world workloads, each over 100M instructions following a 25M-instruction warmup.
  • Achieved up to +21.4% IPC speedup over baseline LRU using BIP, and +15.0% using DIP.
  • Computed geometric-mean IPC speedup across all workloads, showing DIP (+0.45%) and BIP (+1.60%) outperformed LRU with no offline tuning required.
