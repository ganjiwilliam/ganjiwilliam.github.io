Dynamic Cache Replacement Policy Simulator

  • Implemented LIP, BIP, and DIP as custom C++ replacement modules in the ChampSim simulator across 5 real-world workloads, each over 100M instructions following a 25M-instruction warmup.
  • Achieved up to +21.4% IPC speedup over baseline LRU using BIP and +15.0% using DIP.

Fixed-Point FIR DSP Engine & Arithmetic Unit

  • Slashed normalization latency from ~170 cycles (IDIV) and ~80 cycles (SAR/RCR) down to 4 clock cycles by bypassing arithmetic shifts and exploiting direct CL:BH register extraction.
